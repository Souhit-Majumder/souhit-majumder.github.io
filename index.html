plutus

From unorganized mails
to personalized, visually
beautiful expense tracker

Plutus is a personal expense and finance management backend API. Built with Node.js, Express, and MySQL for reliable data management. It provides secure JWT-based authentication and user-specific data access. Users can manage expenses, income, budgets, accounts, savings, loans, and reminders.

gitCompass

Transform a GitHub repository's
raw Git history into
analytical intelligence.

A full-stack developer tool designed for developers onboarding to unfamiliar codebases and tech leads conducting architectural audits. Unlike tools that analyze what code currently is, this platform analyzes how it evolved.

College Chronicles

An app for college students
to manage your college life.

College Chronicles is an all-in-one app that helps students manage their academic and social life. It tracks attendance, predicts safe skips, and keeps exams, timetables, and trips organized. Students can also manage expenses, split group bills, and settle payments easily. By bringing everyday college tasks into one place, it reduces clutter and makes student life easier.
